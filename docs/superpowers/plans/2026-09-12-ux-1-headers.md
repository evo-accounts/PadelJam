# UX-GLOB-01 Headers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every screen in the mobile app uses exactly one `TopBar` variant (`top`, `nav`, `edit`, `wizard`), native headers are switched off, every navigation screen has a back button, and every create/edit screen has a ✕ that confirms before discarding.

**Architecture:** Mechanical adoption of the `TopBar` from the foundations plan. Native Stack and Tabs headers are turned off in the `_layout.tsx` files so no screen draws two headers; each screen renders `TopBar` as the first child of its safe-area container. Right-hand actions that lived in native `headerRight` move into `TopBar.actions`. Create/edit screens derive `dirty` from their form state.

**Tech Stack:** react-native, expo-router (`Stack.Screen` options, `Tabs` options), the `TopBar` primitive, `useConfirm`, `useT('common')`.

**Spec:** `docs/superpowers/specs/2026-09-12-ux-global-rules-design.md` section 1. **Depends on:** the foundations PR (`feat/ux-foundations`) merged.

**Prerequisites:** `git fetch origin && git checkout -b feat/ux-headers origin/main`. Checks: `pnpm --filter mobile typecheck && pnpm --filter mobile lint && pnpm i18n:check && pnpm --filter mobile test`. E2E: the suites that drive converted screens (`01` auth is out of scope; `03` tabs, `04`–`08` events, `09`–`11` communities/groups, `12`/`13` chat/notifications) — run each with `pnpm --filter mobile e2e -- --suite NN` at the end.

## The one pattern

Every converted screen looks like this (a `nav` screen with one action shown):

```tsx
import { SafeAreaView } from 'react-native-safe-area-context';
import { TopBar } from '../../components/ui';   // adjust the relative path
import { useT } from '@padel/i18n';

export default function SomeScreen() {
  const { t } = useT('group');            // the screen's own namespace for the title/actions
  const router = useRouter();
  …
  return (
    <SafeAreaView style={styles.container} edges={['top']}>
      <TopBar
        variant="nav"
        title={t('membersTitle')}
        onBack={() => router.back()}
        actions={[{ icon: '⋯', label: t('more'), onPress: openMenu }]}
      />
      …rest of the screen unchanged…
    </SafeAreaView>
  );
}
```

Rules applied per variant:
- `top`: `variant="top" title={t('title')}` and no `onBack`; actions are the icons that were in native `headerRight`.
- `nav`: `onBack={() => router.back()}`; omit `title` on event, group and community detail screens.
- `edit`: `onClose={() => router.back()} dirty={isDirty}` where `isDirty` compares the form state to its initial values (see Task 4 for the helper).
- `wizard`: `onBack={goBack}` (disabled on the first step by passing `undefined`) and `onClose={onClose}` (the wizard's own dirty-aware close from the foundations plan).

Where a screen previously set `<Stack.Screen options={{ title, headerRight }} />`, delete that element; where a `_layout.tsx` set `headerShown: true`, set it to `false`.

- [ ] **Step 1: A tested dirty helper**

```ts
// apps/mobile/lib/useDirty.test.ts
import { describe, expect, it } from 'vitest';
import { isDirty } from './useDirty';

describe('isDirty', () => {
  it('is false when every field equals its initial value', () => {
    expect(isDirty({ name: 'a', bio: '' }, { name: 'a', bio: '' })).toBe(false);
  });
  it('is true when any field changed', () => {
    expect(isDirty({ name: 'a', bio: 'x' }, { name: 'a', bio: '' })).toBe(true);
  });
  it('treats null, undefined and empty string as the same emptiness', () => {
    expect(isDirty({ bio: '' }, { bio: null })).toBe(false);
    expect(isDirty({ bio: undefined }, { bio: '' })).toBe(false);
  });
});
```

```ts
// apps/mobile/lib/useDirty.ts
import { useMemo } from 'react';

const norm = (v: unknown) => (v == null ? '' : v);

/** True when any field differs from its initial value. Empty string, null and undefined are equal. */
export function isDirty<T extends Record<string, unknown>>(current: T, initial: T): boolean {
  return Object.keys({ ...initial, ...current }).some((k) => norm(current[k]) !== norm(initial[k]));
}

export function useDirty<T extends Record<string, unknown>>(current: T, initial: T): boolean {
  return useMemo(() => isDirty(current, initial), [current, initial]);
}
```
