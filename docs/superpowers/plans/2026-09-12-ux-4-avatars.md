# UX-GLOB-04 User Representation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everywhere a user appears, a circular `Avatar` sits left of the name, with coloured initials when there is no photo; no grey circle, no name on its own.

**Architecture:** The `Avatar` primitive (coloured fallback from the foundations plan) replaces 14 hand-rolled avatar clones, is added to 12 name-only rows, and replaces 3 grey circles. Queries that do not embed `avatar_url` are extended so the rows have the data.

**Tech Stack:** react-native, the `Avatar` primitive, `packages/api` queries, `avatarUrl()` in `apps/mobile/lib/community-images.ts` (turns a storage path into a public URL).

**Spec:** `docs/superpowers/specs/2026-09-12-ux-global-rules-design.md` section 4. **Depends on:** the foundations PR merged.

**Prerequisites:** `git fetch origin && git checkout -b feat/ux-avatars origin/main`.

## The one pattern

```tsx
import { Avatar } from '../../components/ui';
import { avatarUrl } from '@/lib/community-images';

<Avatar uri={avatarUrl(row.avatar_url)} name={row.full_name} colourKey={row.user_id ?? row.id} size="md" />
```
Sizes: `sm` (32) in dense rows (standings, match cards, team slots, sheet rows), `md` (40) in list rows, `lg` (56) in cards and headers, `xl` (80) on the profile header. `avatarUrl` already passes absolute URLs through and resolves storage paths; check its signature in `apps/mobile/lib/community-images.ts` before use.
